# Scanner
Official Google ML Kit document scanner 16.0.0; API 21+, requires Play Services and
at least 1.7GB RAM. First use may download scanning components. Full scanner UI
provides perspective correction, crop, rotation, enhancement and gallery import.
A separate SAF image importer remains available without Play Services.
No external repository copied. Official samples are Apache 2.0; SDK binaries
are governed by Google APIs/ML Kit terms, not claimed to be open source.
References: https://developers.google.com/ml-kit/vision/doc-scanner/android
https://developers.google.com/ml-kit/terms
